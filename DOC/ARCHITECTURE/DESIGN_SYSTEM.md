# Design System

## Overview

LeadPilot AI uses a clean, modern SaaS design system that favors clarity, speed, and content density over visual noise.

## Principles

- Use consistent spacing and typography.
- Prefer reusable components over one-off UI.
- Keep tables, cards, forms, and dialogs visually aligned.
- Use accessible contrast and keyboard-friendly interactions.
- Show loading, empty, success, and error states everywhere that matters.

## Component Families

### Cards

- KPI cards
- Info cards
- Summary cards
- Report cards

### Forms

- Auth forms
- Lead discovery forms
- CRM forms
- Organization settings forms

### Tables

- Paginated tables
- Filterable lists
- Dense admin tables

### Feedback

- Toasts
- Inline validation messages
- Empty states
- Skeleton loaders

## Layout Patterns

- Shell layout for authenticated pages
- Section headers with action buttons
- Grid-based dashboard composition
- Responsive sidebar navigation

## Notes

This document should be updated whenever the app introduces new reusable UI primitives or a visible design pattern shift.
